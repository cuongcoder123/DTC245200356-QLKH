3 Subnet Bridge Phân Vùng Mạng Cô Lập
1. `frontend-net`: Cổng Nginx Gateway, Web App, phpMyAdmin, Grafana. Tiếp nhận truy cập từ bên ngoài.
2. `backend-net`: Web App, MySQL, MySQL Exporter. Không map cổng 3306 ra ngoài Host! Miễn nhiễm hoàn toàn trước quét cổng.
3. `monitoring-net`: Prometheus, Grafana, Loki, Promtail, Node Exporter. Kênh thu thập độc lập.
3 Luồng Dữ Liệu Vận Hành Thời Gian Thực
User Traffic Browser → HTTPS:443 → Nginx SSL → HTTP Proxy → PHP 8.2 → MySQL InnoDB (ACID).
Metrics Scrape Exporters (Host/DB) → Pull 15s → Prometheus TSDB → Grafana Dashboards.
Log Pipeline Nginx + App JSON logs → Tail → Promtail → Push API → Loki → LogQL.
Nguyên Tắc Thiết Kế SRE & An Toàn
Zero Trust Ingress: Nginx là điểm chạm duy nhất, áp dụng 5 Security Headers.
Least Privilege: Web container chạy non-root (`appuser:1001`), chặn Container Breakout.
Resource Ceiling: Giới hạn trần CPU & RAM cho từng container chống cạn kiệt tài nguyên.

CHƯƠNG 6.2: PHÂN TÍCH SỰ CỐ VẬN HÀNH

Thực Thi 3 Câu Truy Vấn LogQL & Sandbox Thử Nghiệm

LOGQL DIAGNOSTICS
Query 1: Lọc Mã Lỗi HTTP 4xx hoặc 5xx từ Nginx Gateway GATEWAY ERRORS
{job="nginx"} |= "status=" |~ "status=[45][0-9][0-9]"
Dùng Regex phát hiện ngay các lỗi 403, 404 hoặc 500/502 sập máy chủ.
Query 2: Thống Kê Tần Suất Theo IP (Phát Hiện DoS / Brute-force) ATTACK DETECTION
sum by (client_ip) (count_over_time({job="nginx"} [5m]))
Gom nhóm IP đếm số request trong 5 phút; phát hiện các cuộc dò quét mật khẩu.
Query 3: Truy Vết Lỗi Giao Dịch Nghiệp Vụ Kho Hàng APP LOG AUDIT
{job="app"} |= "inventory_transactions" |= "ERROR"
Lọc chính xác các bản ghi Web App khi xảy ra lỗi xuất vượt tồn hoặc mất kết nối DB.

CHƯƠNG 7: GIA CỐ BẢO MẬT HỆ THỐNG

4 Biện Pháp Hardening Theo Chuẩn CIS Docker Benchmark

DEFENSE IN DEPTH
1. Thực Thi Non-Root User Trong Container
Tạo người dùng hạn chế appuser (UID 1001) trong Dockerfile. Ngăn chặn triệt để nguy cơ kẻ tấn công thoát container chiếm root máy chủ (Container Breakout).
2. Phân Vùng Mạng Cô Lập (Network Isolation)
Tách thành 3 subnet bridge độc lập: frontend-net, backend-net, monitoring-net. CSDL MySQL hoàn toàn không mở cổng 3306 ra ngoài Internet.
3. Quản Lý Bí Mật An Toàn Qua File `.env`
Không hardcode thông tin nhạy cảm vào code/Dockerfile. Tệp .env được chặn bằng .gitignore ngăn rò rỉ lên GitHub, cung cấp file mẫu .env.example chuẩn.
4. Giới Hạn Trần Tài Nguyên (Resource Limits)
Cấu hình trần CPU/RAM trong `docker-compose.yml` (MySQL: 1.0 CPU, 1024MB; Nginx: 0.5 CPU, 256MB; Web: 0.75 CPU, 512MB) ngăn chặn DoS cạn kiệt tài nguyên máy chủ.
